# Web de Néster Núñez

Página de una sola pantalla en `index.html`. No necesita nada más para funcionar.

## Antes de publicar
1. Pon el número de WhatsApp en `index.html`, en la línea `const WHATSAPP = "53XXXXXXXX";`
2. Sube las fotos a la carpeta `img/` con estos nombres exactos
   - `retrato.jpg` (retrato de portada) y `nester.jpg` (segunda foto), ya incluidas
   - `gavilanes.jpg` (foto del Escambray, horizontal)
   - `periferia.jpg`, `barrio.jpg`, `precio.jpg`, `aqui-no-vive-nadie.jpg` (una foto de cada reportaje)
   Mientras falte una foto, la web muestra un hueco con el nombre del archivo.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub y sube `index.html`, `README.md` y la carpeta `img/`.
2. Settings → Pages → Source: rama `main`, carpeta `/ (root)` → Save.
3. En un par de minutos la web estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Dominio
El archivo `CNAME` apunta la web a thenextphotography.com.
